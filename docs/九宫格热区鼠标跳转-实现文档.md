# 1~9 热区鼠标跳转 - 实现文档

## 功能概述

网页鼠标态下按数字键 `1`~`9`，虚拟光标平滑动画跳转到对应九宫格位置（只移动、不点击，落点确认交给确认键）。

落点采用**九宫格角部偏移定位**：把 WebView 区域三等分为 3×3 格，每个键的落点取"本格内偏向对应角落"的位置——左右列在格内取 25%/75% 宽处，顶/底行取 25%/75% 高处，中间行/列取格中心。这是纯比例计算，天然适配各种分辨率，无需 JS 识别网页元素。

## 设计依据（以 m.qidian.com 为参考）

现代移动网页的典型布局：

- 顶栏按钮贴视口顶角：左上 = 返回/Logo，右上 = 菜单/用户入口 → 键 `1`/`3` 的落点偏向各自格子的上角，普遍落在顶栏真实按钮上；
- 底栏按钮贴视口底角：如起点中文网底栏「菜单 / 书友圈 / 上起点App阅读」→ 键 `7`/`8`/`9` 偏向下角，普遍落在底栏按钮上；
- 中部为正文/对话框 → 键 `5` 落屏幕中心，配合确认键操作对话框。

曾实现过 JS 扫描真实按钮的"智能热区"方案，因落点不准已移除，改为本方案。

## 落点公式

格尺寸 `cw = W/3`、`ch = H/3`；`col = (键-1) % 3`、`row = (键-1) / 3`；格内取样比例：

```
fx = col==0 ? 0.25 : col==2 ? 0.75 : 0.5
fy = row==0 ? 0.25 : row==2 ? 0.75 : 0.5
落点 = (col*cw + cw*fx, row*ch + ch*fy)
```

| 键 | 落点 | 典型目标 |
|----|------|---------|
| 1 | (0.083W, 0.083H) | 顶栏左侧返回 |
| 2 | (0.5W, 0.083H) | 顶栏中部 |
| 3 | (0.917W, 0.083H) | 顶栏右侧菜单 |
| 4 / 6 | (0.083W / 0.917W, 0.5H) | 左右边栏 |
| 5 | (0.5W, 0.5H) | 对话框中心 |
| 7 | (0.083W, 0.917H) | 底栏左键（菜单） |
| 8 | (0.5W, 0.917H) | 底栏中键 |
| 9 | (0.917W, 0.917H) | 底栏右键 |

## 交互细节

- 按下只做光标跳转（`KeyphoneMouseController.animateCursorTo`，180ms 减速动画），确认键才触发点击；动画期间按方向键立即取消、手势接管。
- 仅网页鼠标态生效；`*`/`#` 菜单打开时 `1`~`9` 仍是菜单快捷键（`isMouseModeActive()` 为 false，天然不冲突）。
- Numpad `5` 保留为确认键，不参与跳转。
- 坐标系无换算：WebView 铺满宿主，光标坐标即 WebView 本地坐标，与确认键点击（`dispatchCursorTouch`）共用。

## 代码位置

- `KeyphoneBrowserActivity.kt`：`jumpCursorToZone`（落点计算）、`keyDigitOf`（键值映射）、`dispatchKeyEvent` 鼠标态分支（按键接入）。
- `KeyphoneMouseController.kt`：`animateCursorTo`（平滑跳转动画）。
