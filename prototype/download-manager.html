交互规范审查与设计要领 (Design Spec)

1. 键盘与软键体系 (FEATURE_PHONE_UI_SPEC §4)

  • 主列表态软键明确：左软键统一为 选项，中软键标黄突出默认操作 打开，右软键为 返回。
  • 空列表态智能退化：当无记录时，左右软键自动退化为仅保留 返回，杜绝按空菜单造成认知困惑。
  • 确认键 (OK/5)：直接打开当前聚焦的文件；如果文件失效则提示「文件不存在或已被删除」。

2. 选项菜单 (对标 KeydroidxOptionsDialog)

  • 按左软键 选项 调起官方标准底部抽屉菜单，自带独立顶栏与软键条。
  • 菜单项规划： 1. 打开 (直接打开文件) / 2. 删除 (进入删除分支) / 3. 清空全部记录 (批量管理)。
  • 选项弹窗的软键严格规范：左软键 选择，右软键 返回。

3. 删除决策弹窗 (遵从用户指示与规范 §41/§42)

  • 用户指示响应：列表无须提示文件失效，用户无须感知物理文件是否存在。
  • 删除时统一弹出选择菜单：
    • 选项 1：1. 仅删除记录（保留本地文件，只清理数据库）
    • 选项 2：2. 同时删除文件（清理数据库，若本地文件存在则一并删除，若文件已不存在则静默忽略）
  • 操作纯粹利落，无需多层弹窗干扰。

4. 电脑键盘操作支持 (可在当前网页直接实机体验)

  • 方向键 ↑ / ↓：移动列表或弹窗焦点
  • 确认键 Enter / Space：执行选中项
  • 左软键 Q / F1：打开选项菜单 / 确认选择
  • 右软键 E / Esc / Backspace：返回 / 关闭弹窗
  • 快捷删除 ← / Delete：在列表中直接对聚焦条目触发删除选择
  • 数字键 1 ~ 3：弹窗中快速数字直选
